# App Icons Setup

To complete PWA setup, you need app icons:

## Option 1: Use Online Generator
1. Go to https://realfavicongenerator.net/
2. Upload your restaurant logo
3. Generate icons
4. Download and extract to /public folder
5. Rename files:
   - android-chrome-192x192.png → icon-192.png
   - android-chrome-512x512.png → icon-512.png

## Option 2: Create Simple Icons
1. Create 192x192px PNG with restaurant logo/name
2. Create 512x512px PNG with restaurant logo/name
3. Save as icon-192.png and icon-512.png in /public folder

## Current Placeholders
For now, the app will work without icons.
Add icons later for better install experience.
